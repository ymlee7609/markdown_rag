## 다음 단계 권고

KO 영역은 cover 완료. 다음은 다음 중 택일:

### A. 잔여 5건 cover (응용계층 + WAN)
- 카드 ~10장 (DNS/SMTP/HTTP RFC + Frame Relay + default route concept)
- 전체 cover 95% → 98%+ 가능
- 작업량 작음

### B. False positive 정리 (M2 리포트 권고 항목)
- `concept:acl-extended`의 일반 토큰(`tcp`/`udp`/`permit`/`deny`) 제거
- `alias_dictionary.yaml`의 `require_context_tokens` 정책을 본격적으로 강제하는 `scripts/extract_onto_candidates.py` 작성
- M3 LLM 자동 확장의 기반이 됨

### C. M3 LLM 자동 확장 파이프라인 구현 (큰 작업)
- `scripts/extract_onto_candidates.py` (Stage 1 결정론적)
- `scripts/llm_tag_chunks.py` (Stage 2 LLM)
- `scripts/extract_relations.py` (Stage 3)
- `scripts/enrich_chunks.py` (Chroma metadata patch)
- 본격적으로 RAG 검색에 통합

### D. RAG ablation 측정 (실제 검색 품질 검증)
- `scripts/validate_rag.py`에 `--ontology-mode` 인자 추가
- A(baseline) vs D(보조 코퍼스 + metadata) 4모드 비교
- 합격 기준 Hit@5 +5%p 실측

권장 순서: **B → C → D** (false positive 먼저 정리 → LLM 파이프라인 구축 → 실제 RAG 검증).
권장 우선 작업: **D** (지금까지 만든 53장이 실제 검색에 도움 되는지부터 확인) 또는 **A** (cover율 마무리).
