RAG — 사내 문서를 근거로 답하는 AI

RAG(검색 증강 생성)는 사내 문서를 먼저 검색한 뒤 그 근거 위에서 LLM이 답을 생성합니다. 모델의 환각을 줄이고, 출처가 명확해 현장에서 검증 가능한 답을 제공합니다.

적합 ①

정답이 문서에 명시

매뉴얼·규격에 정답이 기술되어 있어 검색 기반이 강점을 발휘

적합 ②

최신성 유지 용이

재학습 없이 문서 갱신만으로 최신 정보 반영

적합 ③

출처 인용

근거 문서를 함께 제시 → 현장 신뢰·검증 가능

적합 ④

sLLM으로 충분

개방형 대화가 아닌 "근거 있는 Q&A"여서 소형 모델로 대응 가능

솔직한 전제

RAG 성능의 상당 부분은 데이터 품질과 검색 설계에서 결정됩니다. 모델은 종합 역할을 하며, 원문 정제·구조화 노력이 성공의 핵심입니다.

왜 자체 GPU · sLLM 환경인가

01 · 보안

망분리 · 유출 0

외부 클라우드 LLM API 사용 시 민감 자료의 외부 반출이 불가피. 자체 구축은 데이터가 경계 밖으로 나가지 않음 (egress 0)

02 · 속도

무제한 반복 실험

청킹·임베딩·리랭커·프롬프트·파인튜닝 등 수많은 시행착오 필요. 자체 환경은 과금·승인 마찰 없이 자유 반복

03 · TCO

규모 도달 시 유리

다수 사용자·고빈도 질의에서 토큰 과금이 누적되는 클라우드 대비, 고정비 상각 구조가 유리

04 · 자산

사내 역량 자산화

GPU 인프라와 RAG 운영 역량은 향후 CQO·NW의 타 AI 과제에 재사용되는 공통 자산

05 · 주권

모델 내재화

통신 보안·규제 정합. EXAONE 등 LG 패밀리 sLLM의 사내 내재화·통제 용이

균형 잡힌 시각

저빈도라면 클라우드가 더 저렴·신속합니다. 다만 망분리·민감자료·실험 중심이라는 우리 제약에서는 자체 구축이 합리적이며, 시작 속도·초기비용 부담은 단계 투자로 보완합니다.

외부 클라우드 API vs 자체 GPU · sLLM

평가 항목외부 클라우드 LLM API자체 GPU · sLLM (권고)
민감 데이터 · 망분리 적합성✕ 데이터 외부 반출 불가피◎ 경계 밖 유출 0
반복 실험 자유도△ 과금·승인 마찰◎ 무제한 실험
시작 속도◎ 즉시 사용△ 구축 기간 필요
초기 비용◎ 낮음✕ HW 투자 선행
규모 확장 시 비용△ 토큰 과금 누적◎ 고정비 상각
통제 · 커스터마이징△ 제한적◎ 모델·파이프라인 자유
모델 선택 · 내재화△ 제공 모델 한정◎ EXAONE 등 자유 선정

결론. 클라우드가 우위인 항목(시작 속도·초기 비용)도 명확히 존재합니다. 그러나 우리의 제약(망분리·민감자료·실험 중심)을 종합하면 자체 구축이 합리적이며, 우위 항목은 Phase 단계 투자로 보완 가능합니다.
