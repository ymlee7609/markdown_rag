## 개요

RFC 2784는 GRE(Generic Routing Encapsulation)의 현행 표준 정의 문서이다. 2000년 3월 발행, 이전 RFC 1701을 폐기했다. 임의 L3 페이로드를 IP 패킷으로 캡슐화하는 단순화된 GRE 헤더(기본 4바이트)를 정의한다.

## 정의 대상

- **`proto:gre`** — GRE 프로토콜

## 표준 체인

- RFC 1701 (1994) — 원본 GRE (RFC 2784가 폐기)
- RFC 1702 (1994) — GRE over IPv4 (별도 폐기)
- **RFC 2784 (2000)** — 단순화·표준화
- RFC 2890 (2000) — Key & Sequence Number 확장
