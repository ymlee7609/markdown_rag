## 개요

RFC 2616은 HTTP/1.1의 원래(legacy) 정식 표준 문서이다. 1999년 6월 발행. 2014년 RFC 7230~7235로 6개 문서 분할 후속이 폐기 → 2022년 RFC 9110/9111/9112/9113/9114로 재정비됐다. 현재는 historic이지만 산업계 레퍼런스로 여전히 자주 인용됨.

## 정의 대상 (역사)

- **`proto:http`** — HTTP/1.1 (현행 표준은 RFC 9110/9112)

## 표준 체인

- RFC 1945 (1996) — HTTP/1.0
- RFC 2068 (1997) — 본 RFC가 폐기
- **RFC 2616 (1999)** — 1차 단일 표준 (현 OBSOLETE)
- RFC 7230~7235 (2014) — 6개 분할 (모두 OBSOLETE)
- **RFC 9110/9111/9112/9113/9114 (2022)** — 현행

## 주요 기능 (현행도 동일)

- **Persistent Connection (Keep-Alive)**: HTTP/1.1 기본
- **Chunked Transfer-Encoding**: 동적 응답의 사이즈 미리 알 수 없을 때
- **Pipelining**: 응답 대기 없이 다수 요청 (현장에서는 head-of-line blocking으로 거의 미사용)
- **Caching** (`Cache-Control`, `ETag`, `Last-Modified`)
- **Content Negotiation** (`Accept-*`)
