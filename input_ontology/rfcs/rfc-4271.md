## 개요

RFC 4271은 BGP-4(Border Gateway Protocol Version 4)의 현행 표준 정의 문서이다. 자율 시스템(AS) 간 경로 정보를 교환하는 외부 게이트웨이 프로토콜(EGP)로, 인터넷 라우팅의 사실상 표준이다. 2006년 1월 발행, 이전 RFC 1771(1995)을 폐기했다.

## 정의 대상

- **`proto:bgp`** — BGP-4 프로토콜 자체
- **`concept:bgp-as-path`** — AS_PATH 경로 속성
- **`concept:bgp-update-message`** — UPDATE/OPEN/KEEPALIVE/NOTIFICATION 메시지 형식
- **`concept:bgp-finite-state-machine`** — BGP peer FSM (Idle, Connect, Active, OpenSent, OpenConfirm, Established)
