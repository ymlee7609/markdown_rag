## 개요

RFC 1661은 PPP(Point-to-Point Protocol)의 표준 정의 문서이다 (STD 51). 두 노드 간 데이터 링크에서 다중 네트워크 계층 프로토콜을 캡슐화하는 표준 방식이다. LCP(Link Control Protocol)로 링크 협상, NCP(Network Control Protocol)로 네트워크 계층 협상을 한다. PPPoE의 기반 프로토콜.

## 정의 대상

- **`proto:ppp`** — PPP 프로토콜
- **`concept:ppp-lcp`** — Link Control Protocol, 링크 매개변수 협상
- **`concept:ppp-ncp`** — Network Control Protocol, 계층별 협상 (IPCP 등)

## 관련 RFC

- RFC 1334, RFC 1994 — PAP/CHAP 인증
- RFC 2516 — PPPoE (본 RFC 위에 동작)
- RFC 2364 — PPPoA (PPP over ATM)

## 검색 힌트

- "PPP LCP 협상" → 본 RFC + `concept:ppp-lcp`
- "PPP 인증" → 본 RFC + RFC 1994 (CHAP)
- "PPPoE 기반 프로토콜" → 본 RFC + RFC 2516
