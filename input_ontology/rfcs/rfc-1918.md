## 개요

RFC 1918은 인터넷에 라우팅되지 않는 **사설 IP 주소 대역**을 정의한 IETF BCP 문서이다 (BCP 5). 1996년 2월 발행. NAT(Network Address Translation)과 결합되어 사설망에서 사용되는 표준 대역으로, 거의 모든 기업·가정 LAN의 기본 주소 체계를 형성한다.

## 정의된 사설 대역

| 블록 | CIDR | 호스트 수 | 클래스 (legacy) |
|---|---|---|---|
| 24-bit block | `10.0.0.0/8` | ~16.7M | A class 1개 |
| 20-bit block | `172.16.0.0/12` | ~1.05M | B class 16개 |
| 16-bit block | `192.168.0.0/16` | ~65K | C class 256개 |

이 대역의 패킷은 공용 인터넷 라우터가 폐기. 외부와 통신하려면 NAT/PAT 필요.

## 관련 RFC

- **RFC 6598** — Carrier-Grade NAT용 공유 주소 (`100.64.0.0/10`)
- **RFC 4193** — IPv6 ULA (Unique Local Addresses, `fc00::/7`)
- **RFC 6761** — Special-Use Domain Names (본 RFC를 일부 갱신)

## 운영 참고

- 같은 RFC 1918 대역을 양쪽 사이트가 쓰면 VPN/peering 시 충돌 → NAT 또는 IPv6 ULA 권장
- ISP는 customer의 RFC 1918 트래픽을 인터넷에 누설하지 않도록 BCP 38 (RFC 2827) ingress filtering 권장
