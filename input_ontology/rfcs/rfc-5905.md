## 개요

RFC 5905는 NTPv4(Network Time Protocol Version 4)의 현행 표준 정의 문서이다. 2010년 6월 발행, 이전 RFC 1305(NTPv3, 1992)와 RFC 4330(SNTP)을 폐기했다. NTP 패킷 형식, stratum 계층, 시각 동기 알고리즘(clock filter / clock select / clock combine / clock discipline)을 정의한다.

## 정의 대상

- **`proto:ntp`** — NTPv4 프로토콜 본체

## 표준 체인

- RFC 958 (1985) → 1059 (1988) → 1119 (1989) → 1305 (1992, NTPv3) → **5905 (2010, NTPv4)**
- SNTP는 별도 단순화 사양 (RFC 4330) → 본 RFC가 흡수

- RFC 9109 (2021) — NTP Client Source Port Randomization
