## 개요

RFC 2131은 IPv4용 DHCP(Dynamic Host Configuration Protocol)의 정식 표준이다. 호스트가 부팅 시 IP 주소·서브넷·게이트웨이·DNS 등 네트워크 구성 정보를 동적으로 할당받는 절차(DORA: Discover-Offer-Request-Ack)를 정의한다. RFC 1541을 폐기한 후속 버전.

## 정의 대상

- **`proto:dhcp`** — DHCPv4 프로토콜
- **`concept:dhcp-discover`** — DORA 4단계 메시지 교환
- **`concept:dhcp-lease`** — 임대 시간, 갱신(T1/T2/lease)

## 동반 RFC

- **RFC 2132** — DHCP Options and BOOTP Vendor Extensions (옵션 코드 정의)
- **RFC 8415** — DHCPv6 (별도 카드 검토 대상)
- **RFC 3046** — DHCP Relay Agent Information Option (Option 82)
