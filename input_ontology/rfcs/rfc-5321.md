## 개요

RFC 5321은 SMTP의 현행 정식 표준이다. 2008년 10월 발행, 이전 RFC 2821(2001)을 폐기. ESMTP(Extended SMTP) 확장을 포함하며, MAIL FROM/RCPT TO/DATA의 트랜잭션 모델, 응답 코드, 상태 코드를 정의한다.

## 정의 대상

- **`proto:smtp`** — SMTP/ESMTP

## 표준 체인

- RFC 788 → 821 (1982) → 2821 (2001) → **5321 (2008)**

## 동반 표준

- **RFC 5322** — Internet Message Format (메일 헤더·본문)
- RFC 6531 — SMTPUTF8 (국제화 메일)
- RFC 7504 — NULL MX (본 RFC 갱신)

## 검색 힌트

- "SMTP 표준" → 본 카드 + `proto:smtp`
- "SMTP MAIL FROM RCPT TO" → 본 카드
- "RFC 2821" → 본 카드가 폐기
