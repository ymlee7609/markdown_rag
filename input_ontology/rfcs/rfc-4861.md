## 개요

RFC 4861은 IPv6 NDP(Neighbor Discovery Protocol)를 정의한다. IPv4의 ARP를 대체하는 IPv6 주소 해석, 라우터 발견, 자동 주소 구성(SLAAC) 보조, 중복 주소 감지(DAD) 등을 수행한다. ICMPv6 메시지를 통해 동작한다.

## 정의 대상

- **`proto:ndp`** — Neighbor Discovery Protocol
- **`concept:ndp-router-discovery`** — RS/RA 메시지로 라우터·prefix 발견
- **`concept:ndp-address-resolution`** — NS/NA로 IPv6 ↔ MAC 매핑 (ARP 대체)
- **`concept:ndp-duplicate-address-detection`** — DAD, 주소 충돌 감지

## 관련 RFC

- RFC 4862 — IPv6 SLAAC (NDP의 RA를 사용)
- RFC 4443 — ICMPv6 (NDP가 사용하는 메시지 전송 계층)
- RFC 8200 — IPv6 본체 사양
