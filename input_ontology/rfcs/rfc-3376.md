## 개요

RFC 3376은 IGMPv3(Internet Group Management Protocol Version 3)을 정의한다. IPv4 호스트가 라우터에 멀티캐스트 그룹 가입/탈퇴를 알리는 프로토콜로, v3는 source-specific multicast(SSM)을 지원해 특정 송신원으로부터 오는 트래픽만 필터링할 수 있다. IPTV·실시간 스트리밍·금융 시세 배포 등에 사용된다.

## 정의 대상

- **`proto:igmp`** — IGMP 프로토콜 (v3가 현행)
- **`concept:igmp-snooping`** — L2 스위치가 IGMP 메시지를 들여다보고 멀티캐스트 포워딩 최적화
- **`concept:igmp-source-specific`** — SSM, EXCLUDE/INCLUDE 필터

## 표준 체인

- RFC 1112 (1989) — IGMPv1
- RFC 2236 (1997) — IGMPv2 (본 RFC가 폐기)
- **RFC 3376 (2002)** — IGMPv3 현행
- RFC 4604 (2006) — IGMPv3로 SSM 사용
