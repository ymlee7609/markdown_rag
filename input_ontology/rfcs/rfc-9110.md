## 개요

RFC 9110은 HTTP의 현행 **의미론** 표준이다 (STD 97, 2022년 6월). 메서드, 상태 코드, 헤더 필드, content negotiation, authentication 등 HTTP/1.1/2/3 공통 의미론을 정의한다. 메시지 문법은 별도 RFC로 분리:

- **RFC 9111** — HTTP Caching
- **RFC 9112** — HTTP/1.1 Message Syntax
- **RFC 9113** — HTTP/2
- **RFC 9114** — HTTP/3

## 정의 대상

- **`proto:http`** — HTTP 의미론 본체

## 폐기한 RFC (9개)

이전 6개 분할(RFC 7230~7235)과 기타 보완 RFC들을 통합 대체:

- RFC 2818, 7230~7235, 7538, 7615, 7694
