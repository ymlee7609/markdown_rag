## 개요

RFC 2328은 OSPF(Open Shortest Path First) Version 2의 정식 표준 정의 문서이다 (STD 54). 1998년 4월 J. Moy가 발행했으며, 이전 RFC 2178을 폐기하고 현행 OSPFv2 표준의 기준이 되었다. IPv4 단일 자율 시스템 내부 라우팅을 위한 link-state IGP 프로토콜의 동작·메시지 형식·상태 기계를 정의한다.

## 정의 대상

이 RFC가 정의하는 핵심 엔티티:

- **`proto:ospf`** — OSPFv2 프로토콜 자체
- **`concept:ospf-lsa`** — LSA(Link State Advertisement) Type 1~5
- **`concept:ospf-area`** — Area 개념, backbone area (0.0.0.0), stub area
- **`concept:ospf-neighbor`** — Hello 프로토콜, 인접 관계 형성 FSM, DR/BDR 선출
