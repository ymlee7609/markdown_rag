## 개요

RFC 8200은 IPv6(Internet Protocol Version 6)의 현행 표준 정의 문서이다 (STD 86). 2017년 7월 발행, 이전 RFC 2460을 폐기하고 IPv6 사양을 인터넷 표준으로 격상시켰다. 128비트 주소, 단순화된 헤더, 확장 헤더(Extension Header) 체계를 정의한다.

## 정의 대상

- **`proto:ipv6`** — IPv6 프로토콜
- **`concept:ipv6-header`** — 40바이트 고정 헤더 구조
- **`concept:ipv6-extension-header`** — Hop-by-Hop, Routing, Fragment, AH, ESP, Destination Options

## 관련 RFC (IPv6 family)

- **RFC 4861** — Neighbor Discovery for IPv6 (`proto:ndp`)
- **RFC 4862** — IPv6 Stateless Address Autoconfiguration (SLAAC)
- **RFC 5340** — OSPF for IPv6 (OSPFv3)
- **RFC 8415** — DHCPv6
- **RFC 4291** — IPv6 Addressing Architecture

## 표준 체인

- RFC 1883 (1995) → RFC 2460 (1998) → **RFC 8200 (2017)** 현행

## 검색 힌트

- "IPv6 헤더 구조" → 본 RFC + `concept:ipv6-header`
- "IPv6 확장 헤더" → 본 RFC + `concept:ipv6-extension-header`
- "IPv6는 어느 RFC?" → 본 RFC (STD 86)
- "RFC 2460" → 폐기, 본 RFC가 대체
